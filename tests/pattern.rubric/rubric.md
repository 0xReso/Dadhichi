# Rubric: pattern.rubric

| # | Check | Pass condition | Decided by |
| --- | --- | --- | --- |
| 1 | Size | Between 5 and 12 checks | code |
| 2 | Decidable | Every pass condition can be decided by a quote, a count, or a named absence; no bare adjective where a number or comparison fits | grader |
| 3 | Matters | Every check is about something the stated reader would notice; none is unfailable | grader |
| 4 | No overlap | No single plausible fault would fail two checks | grader |
| 5 | Failures covered | Every supplied failure is caught by a named check that also catches a reworded instance of the same fault | grader |
| 6 | Marked | Each check is marked code or grader, and every check that plain code could run is marked code | grader |
| 7 | On task | Includes a check that the output does the asked job and not an easier nearby one | grader |
| 8 | Recall (inputs 1 and 1b) | Covers at least 6 of explain checks 1, 2, 3, 4, 5, 6, 9 and 11b on input 1, and at least 4 on input 1b | grader |
| 9 | Clean output | Only the table, the grading conventions and, for a vague job, one assumption line | grader |
| 10 | Conventions | Each whole-output check specifies its unit and single-instance verdict, and its threshold reflects the consequence for the reader | grader |
| 11 | Assumption | Only input 5 starts with “Assumed:” and names the reader and output in that line | grader |
