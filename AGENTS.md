# Resuming work on Dadhichi

Start with [the current handoff](loop/STATE.md). It records the last completed round, links to the evidence, and names the next task. Resume the unfinished item there. When it is complete, use the first open item in the [backlog](loop/BACKLOG.md).

For prompt changes or evaluation runs, follow the [round protocol](loop/LOOP.md) and the [system design](Dadhichi%20Master%20Prompt%20Library%20System%20Design.md). The [changelog](CHANGELOG.md) explains earlier version decisions.

At the end of a round, update the handoff with the result, the evidence path, anything still pending, and the exact next step. Commit it alongside the work so another agent checking out that revision can resume.
